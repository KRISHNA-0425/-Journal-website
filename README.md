# ASETR — Advances in Science, Engineering and Technology Research

Official journal website for **Advances in Science, Engineering and Technology Research (ASETR)** — a rigorous, open-access, double-blind peer-reviewed scholarly platform bridging fundamental science, engineering innovation, and technology.

## Features

- **Dual Theme System**: Switch seamlessly between Dark (neutral gray) and Light (warm beige) modes with `localStorage` persistence.
- **Theme-Adapted Logos**: Custom transparent PNG logos (`logo-dark.png` and `logo-light.png`) tailored for each theme.
- **Glassmorphism & 4-Grid Design**: Solid color tokens, `48px` architectural grid pattern, and frosted-glass surfaces without heavy gradients.
- **Multi-Page Navigation**:
  - **Home**: Hero section, research domains grid, journal highlights, editorial board preview, and call for papers.
  - **Aim & Scope**: Journal mandate, publication metadata, and categorized subject coverage.
  - **Editorial Board**: Detailed profiles, specializations, affiliations, and direct contact info for editorial leaders.
  - **Submit Paper**: Interactive 5-step submission guide, manuscript requirements, and ethics policy.
  - **Contact**: Editorial inquiry form, direct editor contacts, and expected response times.

## Tech Stack

- React + Vite
- React Router DOM
- Tailwind CSS
- Lucide React Icons
